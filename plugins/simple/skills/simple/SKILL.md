# NavAIgate Simple

Use BB's own conversation, model controls, files, terminal, splits and Start Side Chat. Simple changes the project/chat list only; it does not add a second chat engine.

- **New chat** opens BB's composer in the selected project.
- **Filter chats** filters the active sidebar data. BB's native search remains available for broader search.
- Right-click or open the row's **Actions** button for BB's own rename, pin, archive and other thread actions.
- **Features** shows the real installed state of Helper Desk, Cache Clock, Reflect and Screen Share. These plugins keep their own settings.
- **Appearance** opens BB Settings. Select NavAIgate Simple and BB's light, dark or system mode.
- **Open BB Overlay guide** resumes the separate guide. **Replay guide** in the Simple settings deliberately starts it again.

Do not tell a user a guide or tool is enabled without checking its actual state. Selecting a sidebar is not permission to uninstall another plugin or remove its data.
