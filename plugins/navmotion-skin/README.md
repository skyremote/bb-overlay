# NavMotion Skin for bb

The NavMotion film look as a bb skin, plus Markdown in the chat box.

- **NavMotion Dots**: calm paper that never stops moving.
- **NavMotion Live**: the ground shows what your agents are doing.
- **NavMotion Tunnel**: the dark studio from the films.
- **Skin button** in the sidebar footer: every skin, NavAIgate and ChatGPT included, one click away.
- **Markdown chat box**: live bold, italics, tables and more while you type, and a Preview tab on the side.

Install: `bb plugin install git:https://github.com/skyremote/bb-overlay.git@main --plugin navmotion-skin`, then pick a skin from the Skin button.
Needs bb 0.47 or later.
Edit the skins in `themes/src/` and run `python3 scripts/build-themes.py`.
See `skills/navmotion-skin/SKILL.md` for the details.
