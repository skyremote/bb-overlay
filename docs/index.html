A plugin for bb

NavAIgate Workspace

So I use bb every day to run Claude, Codex and Cursor side by side, and the thing I kept losing was what each one was actually doing, so we built a sidebar that shows what every harness is working on, a to-do list that lives next to the chat it came from, and a board that moves when the work moves. This page is how it all works, one piece at a time.

Step one

Install it in one command

You need bb 0.45 or later, on a Mac or on Linux, and at least one harness signed in. Open bb, then paste this one line into a terminal, and it installs the workspace, the Kanban board, folders, the agent board and bb's Tasks, then turns on the NavAIgate theme and rail.

curl -fsSL https://raw.githubusercontent.com/skyremote/bb-overlay/main/install.sh | bash

Like to read a script before you run it? Good habit. Read install.sh first, or see exactly what it would do without changing anything with curl -fsSL https://raw.githubusercontent.com/skyremote/bb-overlay/main/install.sh | bash -s -- --dry-run. It's safe to run again any time to update everything, it never removes anything, and if you already use a different NavAIgate rail it leaves your look alone.

Then reload bb and open Home to walk through Set up. Not technical? The step-by-step install guide walks you through it.

Install by hand. The same thing, one plugin at a time, then Settings, Appearance: the NavAIgate theme and the NavAIgate rail as the thread list.

bb plugin install git:https://github.com/skyremote/bb-overlay.git@main --plugin workspace
bb plugin install git:https://github.com/skyremote/bb-overlay.git@main --plugin kanban
bb plugin install git:https://github.com/VKirill/bb-plugin-project-folders.git@v0.6.19
bb plugin install git:https://github.com/aaronphifer/bb-plugin-agent-board.git@semver:^0.6.1
bb plugin install tasks

Projects & Sections (folders) by VKirill and Agent Board by aaronphifer are free MIT plugins made by other people. They aren't part of BB Overlay, and they install from their own repositories so they keep their own updates.

Folders need the Projects & Sections plugin, to-dos are stored in bb's own Tasks plugin, and the usage dock reads bb's Account Pooler if you use it. If one of those isn't there, the rest still works, and that part just doesn't show.
The sidebar

See what every harness is working on

The left-hand side reads like a run sheet now, and the card at the top tells you what's working right now, with a small gold lattice that turns while a chat is busy, and how many chats need you.

  • Every chat has two lines: its title, then the model and effort it runs on (for example Opus · High, or Codex · GPT-6.1 Sol · High), how many of its sub-agents have finished and its git branch. The mark on the left says what it needs, and a gold spinner shows it is working. The row at the top filters to one harness.
  • A chat with sub-agents starts folded. Click its done/total chip, or press → and ← on the row, to show or hide them. While folded, the chip shows a spinner when one is working and a red dot when one needs you, and those sub-agents peek out until they finish. Right-click the rail for Expand all and Collapse all.
  • Each project has its own colour, a dot on its heading and a bar down its chats; right-click the heading and choose Colour to change it. For one line per chat, right-click the rail and choose Compact rows.
  • bb's own navigation sits under a Navigate row. Click it, or press ⌘⇧B, to fold it to one line so the rail moves up, and right-click it to hide it entirely; right-click the rail and choose Show navigation to bring it back.
  • Chats sit under their project, and with Projects & Sections installed they sit inside your real folders on disk.
  • Click a section heading to fold it, and drag a heading above another one to change the order.
  • Right-click anything, a chat, a folder, a project heading or a tag chip, and you get the full menu for it.
Tags and flags

Tag it, flag it, come back to it

  1. Open Tags beside Select, choose New tag…, type a name, click the small square to pick a colour, and press Enter.
  2. Right-click a chat, go to Tags, and tick the tags you want on it. To show only those chats, open Tags beside Select and tick one or more; Manage tags in the same menu renames, recolours and deletes them.
  3. Right-click a chat, go to Come back later, and pick why. It moves into its own section at the top so you can't miss it.
  4. To clear a flag, right-click it again and choose Clear the flag.

Folders

Your real folders, in the sidebar

Each project is a folder on your drive, and the folders you add show up underneath it, and the point is you choose which ones you want to see, so the project root stays the same and you organise inside it.

  1. Hover a project heading and press the folder-plus button for a new folder, or the open-folder button to add folders that already exist on the drive.
  2. Drag a chat onto a folder to file it there. That only changes where it's listed, and nothing moves on disk.
  3. Start a chat inside a folder with the speech-bubble button on the folder, and the agent works in that folder, so its files land there.
  4. Right-click a folder to rename it, add a subfolder, move it, copy its path, or take it off the sidebar. Taking it off the sidebar keeps every file.
Doing things in bulk

Select a few at once

Hold ⌘ and click to pick chats one by one, hold ⇧ and click to pick a run of them, or press Select next to the harness chips to get checkboxes. "Needs you" has its own select-all button. A bar appears at the bottom where you can flag, tag, pin, archive or delete the lot, and delete asks you once for the whole batch. Press Esc to clear it.

To-do

Say it once, and it's on the list

The quickest way is just to tell the agent, so for example "we've got the hero copy, a pricing FAQ and the nav fix to do", and it adds three items linked to that chat, and you'll see them straight away.

  1. Open the list on the right with ⌘ ⇧ D (Command-Shift-D), or press the To-do button in the chat header, which also shows how many are open.
  2. Switch between This chat, the chat's folder and Everything at the top.
  3. Type in the box and press Enter. Paste a list and every line becomes its own item.
  4. Click the ring next to an item to tick it off, double-click the text to rename it, and right-click to move it, link it to this chat or folder, or delete it.
Folders in the sidebar show a small count of open items inside them. The agent tool only appears in chats started after you install the plugin.
The Board

A board that moves itself

Board is in the sidebar navigation, and it has four columns, To do, Doing, Check and Done, and the difference is that it moves on what the chats are actually doing, not on what an agent says about itself.

  • When a chat linked to an item starts working, the item moves to Doing on its own, with the lattice turning.
  • When every linked chat has finished, it moves to Check, ready for you to look at.
  • Nothing is ever moved to Done for you. Drag any card to put it where you want.
  • The chips at the top filter by project, and the box in To do adds straight to the board.
Usage

Know where you stand before you hit a limit

Under the chat box there's a line that shows how much of the context the chat has used, with a small dial and a tick where auto-compaction starts, and next to it the plan and the session and weekly windows of the account that chat is running on. If you run more than one subscription through bb's Account Pooler, it shows the one that chat is actually using.

Rest the pointer on that line for a moment, or Tab to it and press Enter, and a usage card opens. It charts this session and this week since each window opened, draws a dotted forecast to the reset and warns you before you cross 90%, and gives your burn rate, the time to the limit and the chats that used the most. Small tabs switch between every Claude, ChatGPT and Cursor account you have.

  • The plugin records each account every 3 minutes from readings bb already has, so it never asks the providers for more. Cursor is checked every 15 minutes.
  • Forecasts are straight lines, and the busiest chats are an estimate from each finished turn's tokens; the card says so.
Voice

Talk to it, and hear what happened

Press Talk in the chat header, or ⌘ ⇧ E, and just say what you want done, and Savvy, a voice agent on ElevenLabs, writes it up as a clear prompt and sends it to whichever harness is in that chat. When the harness finishes, she tells you in a couple of sentences what was done, what's left and whether it needs you, and the Voice tab on the right keeps the whole transcript.

  • Ask "what's it doing?" or "what did it say?" and she checks the chat for you.
  • Say "stop it" and she stops the harness, or list things to do and she adds them to the to-do list.
  • It needs an ElevenLabs API key in the plugin settings. The key stays on your bb server, and ElevenLabs bills the conversation to your account.
Agents

See the whole run, and start an agent when you want one

Open Agents on the right of any chat, or press ⌘ ⇧ A, and This run shows the chat and every sub-agent under it as a tree, live, with which harness each one is on, whether it's working or needs you, and a session log of every change while the panel is open. Your agents lists every agent you've defined in ~/.claude/agents, grouped like a crew, chief of staff first, then the leads, then the specialists. Pick one and it starts on the model its file pins, and a lead can run in its own chat so it can bring in sub-agents of its own.

  • Pick a role (Explorer, Worker, Reviewer, Researcher) or one of your own agents, choose the harness and model with bb's own picker, write the task and press Spin up.
  • It starts as a child of the chat you're in, in the same workspace, and appears in the tree and in the rail straight away.
  • Click any card in the tree to jump into that agent's chat.
Charts in replies

Answers that come back as a chart

Agents can draw a real chart in a reply instead of a list of numbers, and the plugin teaches them how. If you want to write one yourself, it's one line:

::nav-chart{kind="bars" title="Threads by harness" data="Claude:26,Codex:9,Cursor:4" highlight="Claude"}

The kinds are bars, stats, split and steps, and note adds a source line underneath.

Two more work the same way. ::nav-links turns a list of links into cards in each platform's own colour, so LinkedIn is blue, YouTube is red and X and Threads are black, and ::nav-pipeline draws an agent stack, who plans, who runs side by side, who reviews and who watches, with a session log underneath.

::nav-links{title="Posted" items="https://www.linkedin.com/... https://x.com/... https://youtube.com/..."}
::nav-pipeline{layers="Opus|plans|orange ; Worker|edits|blue , Explorer|reads|blue ; Opus|reviews|orange" side="Fable|advisor|plum"}

Data and privacy

What it touches

  • To list your to-dos and see which account a chat runs on, it opens the Tasks and Account Pooler databases on your own machine read-only, and every change goes through those plugins' own controls.
  • Tags, flags, section order and folder links are kept in bb's plugin storage on your bb server, so every window on that machine shows the same thing.
  • The theme loads IBM Plex and Fraunces from Google Fonts, and there's no tracking. The rail, tabs, folders, groups, the to-do panel and board, charts and the theme all work without any account or key.
  • Some features are optional and use your own keys if you want them: the voice agent (ElevenLabs), Inbox, Agenda and Calendar (Composio, with Gmail and Google Calendar connected), booking links (Calendly), Sort with Jev (TypeSafe), Social (Blotato) and the always-on machine (a second machine of your own). Your keys are saved on your own machine, and nothing is sent to NavAIgate.

To go back to bb's own sidebar, choose it in Settings, Appearance, Sidebar, and to remove the plugin, run bb plugin uninstall navaigate-workspace, which also deletes its tags, flags and folder links, while your to-do items stay in bb Tasks.
